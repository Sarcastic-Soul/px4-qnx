With the load at FIFO 245, above EKF2 (239), the estimator ran once in 30 s. Strict priorities do what you set, so choosing them is a design decision. A kernel trace shows the rate-controller thread gets a CPU a median 2.6 µs after it becomes ready. All results and caveats.

what the port uses

QNX features, and where to find them

PX4's POSIX layer got a __PX4_QNX path, the same way it already handles macOS. The interesting parts are where QNX differs from Linux.

  1. Real priorities, 1 to 253

    QNX 8.0 reserves 254 and 255. PX4's range is capped and every thread runs SCHED_FIFO. Checked by tests/test_priorities.sh.

  2. Explicit scheduling fix

    Threads inherit their creator's scheduling unless PTHREAD_EXPLICIT_SCHED is set. Before the fix every work queue silently ran at 253.

  3. A resource manager inside PX4

    /dev/px4/state serves live vehicle state to any QNX process. Built on resmgr_attach, iofunc_* and per-open OCBs.

  4. Fixed-priority channel

    _NTO_CHF_FIXED_PRIORITY keeps the state server at 97 even for a FIFO-253 reader, so it never runs above the flight controller.

  5. 10 kHz kernel tick

    Timers round to the tick. Booting procnto -C 10000 through mkqnximage cut loop jitter about 6x, with no PX4 change.

  6. Process isolation and dumper

    Mid-mission, a separate process hogs CPU and 512 MiB, then segfaults. The mission completes and QNX saves a core file.

Write a QNX 8.0 resource manager and control its priority

Build /dev/prio in about 150 lines of C, then measure how message passing hands the client's priority to the server. See a 1 kHz loop lose 200 ms to inheritance, and a fixed-priority server cause a 1.7 s priority inversion. No PX4 needed.

Run it yourself

The repo holds only patches, scripts, tests and docs. Upstream PX4 is fetched at the pinned tag.

  • Linux x86_64 host with KVM
  • QNX SDP 8.0.5 (free non-commercial license)
  • git, CMake, Ninja, QEMU, uv
  • Optional: QGroundControl

scripts/fresh-clone-test.sh runs the whole chain from an empty directory.

scripts/fetch-upstream.sh   # PX4 v1.17.0
scripts/apply-patches.sh    # 6 QNX patches
scripts/setup-venv.sh
scripts/build.sh            # QNX ELF via qcc
scripts/make-vm.sh          # mkqnximage
scripts/run-vm.sh
scripts/deploy.sh
scripts/px4-vm.sh start     # SIH quad
tests/run-all.sh            # 7 checks
